# 卤味透明底商品图批量生成

把真实卤味产品照重制为电商可用的商品图。核心原则：**形态必须来自实拍图，只重做背景、餐具和光线**。

三条优先级，冲突时按此顺序：

1. **产品实拍图（参考图1）里的食品形态 > 提示词里的形态描述**。模板正文不含任何品项的专属词，形态一律走变量；盘子外观单独以参考图2为准。
2. **背景由用户选，分两级问**：第一轮选大类（透明／纯色／场景），第二轮选子类。不替他决定。例外：用户最初的请求里已经描述了场景，则跳过第一轮直接默认场景背景。未指定时用透明底并说明。
3. **光泽要强**，但用正向描述控制，不用否定式压高光。

配方来源：2026-10-30 卤鸭胗透明底商品图项目，经多轮返工验证。标注「实测」的是踩坑验证过的结论。

## 1. 固定视觉配方（不要逐次改动）

| 项目 | 固定值 | 说明 |
| --- | --- | --- |
| 背景 | 两级选择：**第一轮选大类（T 透明／S 纯色／C 场景），第二轮选子类**。开批前由用户选择；若用户最初的请求里已描述场景，直接默认 C 场景背景 | 用户 2026-10-30 要求背景可选，且要拆成两级。未指定时默认 T 透明底，并说明用的是默认值 |
| 背景与产品的色彩隔离 | 纯色背景（S1–S5）必须写明「背景不与产品发生色彩混合」；场景背景（C）**允许环境光**，但必须限定「不改变产品本色、不把白盘整体染色」 | 用户 2026-10-30：纯色背景不能影响产品颜色；场景背景可以有环境光 |
| 餐具 | 固定使用纯白哑光陶瓷窄沿圆形浅盘，居中，占画面宽度约 85% | 以随附的空盘参考图锁定盘型、盘沿、材质与视角；见下方参考图说明 |
| 机位 | 45° 斜俯视，85mm 等效焦段，f/4 浅景深 | 俯拍显平淡，45° 才有立体感和食欲 |
| 主光 | 左前 45° 大面积柔光箱，压出主体明暗结构 | — |
| 点状高光 | 顶部偏前加一盏窄束小硬光，在凸起处制造 2–4 个锐利的点状高光，大小不一、位置不居中 | 「油亮」最直接的来源。只有柔光会显得发干 |
| 背逆光 | 右后方低位背逆光穿过卤汁油膜，凸起边缘与薄处呈半透明琥珀红，并勾出一条细金红线 | 让卤汁通透有层次，是食欲感的关键 |
| 补光 | 左前低角度白色反光板，让凹陷与缝隙处也带一层湿润反光、不死黑 | 单灯纯柔光会让细节发干 |
| 材质 | 表面覆一层薄而黏稠的卤汁油膜：凸起处有细长的条状高光带，低洼处油层积得更厚、反光更亮，高光沿表面纹理的凹凸断断续续分布，碎而亮 | 油膜要连续、能反射环境光，不是干壳 |
| 反塑料感 | 禁止的是「一整片平滑连续的镜面反光」，**不是禁止高光本身** | 实测：写成「避免塑料感与均匀镜面高光」会被理解成降低高光，结果发干发哑 |
| 盘缘处理 | 透明底时盘子轮廓靠自身明暗与高光勾出，边缘干净锐利，不带白色或灰色描边、光晕、白边 | 透明底没有背景对比，白盘边缘容易糊或描白边 |
| 投影 | 按背景类型定，规则已写进各背景预设：透明底／绿幕／蓝幕**不加投影**；纯白底加极淡柔和投影勾盘缘；黑底加柔和接触阴影 | 不要在各预设之外另写投影描述，会互相打架 |
| 质感 | 保留真实卤味的粗粝肌理，同时保留油亮光泽，两者不冲突 | 肌理靠高光沿纹理断续来体现，不是靠压掉高光 |
| 点缀 | **无**。盘面只放产品本身，不放辣椒碎、白芝麻、香草等任何点缀 | 用户 2026-10-30 明确要求：盘子里不要有辣子和白芝麻 |
| 尺寸锚点 | 单件≈盘内径 1/3；多件每件≈4 成、件间差异≤一成，取值见 `{{size_anchor}}` | 实测：写百分比模型基本不执行，必须用「留白宽度大于一件本身」描述 |
| 文字 | 无任何文字、标签、水印 | 需要文案请后期加，不要交给模型渲染 |
| 比例 | 方形 1:1，1024×1024 | — |

**固定盘子参考图**：[assets/standard-white-plate.png](assets/standard-white-plate.png)。路径相对于本 `SKILL.md` 所在目录解析，不依赖当前工作目录。每张商品图都同时使用当前产品实拍图和这张空盘图，由模型**直接生成产品放在盘子里的完整画面**，不做抠图或后期合成。

### 2.1 `{{product_structure}}` 写法指南

按「**整体形状 + 长短粗细比例 + 走向/盘绕方式 + 表面纹理 + 边缘或断口特征**」五项写，缺一项就容易失真。**必须描述实拍图里真实存在的东西，不要套用其他品项的词。**

已验证示例（卤鸭胗，可直接复用）：

```
两瓣饱满的肌肉块中间有明显凹槽分界，侧翼薄膜状筋膜自然外翻并带细密褶皱，边缘不规则、有轻微撕裂感，整体轮廓不对称、不规整
```

待核对示例（卤鸭肠，据常见形态填写，**请按你的实拍图核对后再用**）：

```
细长的管状，管壁薄而略带韧性，表面有细密的环形纹理与轻微起伏，整体盘绕打结成一团，中段有交叠处，端口断面能看到管腔，边缘有轻微不规则的撕裂与卷曲
```

**禁止写法**（实测会把产品抹成光滑椭球，或画成别的食材）：

- ❌ 写其他品项的专属词。例如给鸭肠写「两瓣肌肉块」「膜翼向内收拢」「橄榄形轮廓」
- ❌「筋膜不外扩」「不形成翼状轮廓」「轮廓紧凑完整」这类收边描述，会删掉产品最有辨识度的特征
- ❌ 只写「椭圆形」「饱满光滑」等泛化形容词
- ❌ 堆叠「顶级、8K、杰作」等无信息量修饰

用户无法描述结构时：查看其实拍图，从图中观察归纳后再写，并向用户说明该描述来自图像观察而非其原始表述。

### 2.2 `{{size_anchor}}` 三个预设

| 适用 | 取值 |
| --- | --- |
| 块状／枚状，单件 | `长度约为盘内径的三分之一` |
| 块状／枚状，多件 | `每件长度约占盘内径的四成` |
| 细长／盘绕类（鸭肠、鸭脖、鸭翅） | `盘绕或伸展后的整体外径约为盘径的三分之一，不要画成占满盘子的大块` |

细长类必须用第三个预设。用「长度」描述盘绕物会让模型把东西拉直或放大。

### 2.3 背景：两级选择

背景**分两轮问**，不要一次性把六个选项摊给用户。

**第一轮：只问大类，三选一**

| 大类 | 含义 | 下一轮 |
| --- | --- | --- |
| **T 透明** | 没有背景，只有白盘与产品 | 无子类，确认后直接出图 |
| **S 纯色** | 单一纯色底，颜色整片均匀 | 第二轮选具体颜色（S1–S5） |
| **C 场景** | 有环境、有环境光、有虚实 | 第二轮选场景类型 + 环境光 |

用户答「你定」时才用 T，并明确告知用的是默认值。

**第二轮：按大类展开子类**

- 选 **T** → 不问了，直接确认。
- 选 **S** → 给 5 个颜色子类，见 §2.4。
- 选 **C** → 同一轮里问场景类型（6 个）+ 环境光（5 个），见 §2.4。

### 2.4 各子类的预设文本

**凡是用纯色背景（S1–S5），都必须带上「背景不与产品发生色彩混合」这一段**，否则模型会把底色反光打到产品和白盘上，出图颜色发偏。这段已经写进各预设里，不要删。

**T. 透明底（默认）**

```
背景为完全透明，画面里只有白盘和产品本身，不要任何背景色、桌面、台面或地面，盘底不加投影，盘沿靠自身的明暗与高光勾出轮廓，边缘干净锐利，不带白色或灰色的描边、光晕与毛边，导出为带透明通道的PNG
```

**S1. 纯白底**

```
背景为纯白色，色值#FFFFFF，中性色温5500K，白盘与白底不带黄调，背景整片均匀、无渐变。盘底只有一层极淡柔和的自然投影勾出盘缘。背景不与产品发生色彩混合：产品与白盘表面不出现背景色的反光、溢色或染色，白盘保持中性白，产品原本的红棕色调不被背景带偏，边缘不泛白
```

**S2. 黑底**

```
背景为极深的近黑色，色值约#0C0C0C，从画面中心向四角有极轻微的暗角过渡，不要出现纹理、台面接缝、明显色块或灰雾。白盘与背景形成干净的高对比，盘底只有一层柔和自然的接触阴影，阴影紧贴盘底、不外扩成大团灰雾。加强右后方轮廓光，让白盘边缘与产品凸起边缘从黑底中清晰分离，边缘不糊、不溶进背景。背景不与产品发生色彩混合：深色背景不把产品压暗、不使红棕调偏冷或发灰，白盘保持中性白，产品边缘不泛黑
```

**S3. 绿幕色**

```
背景为均匀的纯绿幕色，色值#00B140，整片背景颜色完全一致，无渐变、无明暗变化、无纹理、无台面接缝，也不要出现桌面或地面。盘底不加投影，避免在绿幕上留下阴影影响抠像。背景不与产品发生色彩混合：产品与白盘表面不出现任何绿色反光、绿色溢色或绿色边缘光，白盘保持中性白，产品红棕调不被染绿，边缘不泛绿
```

**S4. 蓝幕色**

```
背景为均匀的纯蓝幕色，色值#0047BB，整片背景颜色完全一致，无渐变、无明暗变化、无纹理、无台面接缝，也不要出现桌面或地面。盘底不加投影，避免在蓝幕上留下阴影影响抠像。背景不与产品发生色彩混合：产品与白盘表面不出现任何蓝色反光、蓝色溢色或蓝色边缘光，白盘保持中性白，产品红棕调不被染蓝，边缘不泛蓝
```

**S5. 自定义纯色**

```
背景为单一纯色，色值{用户指定值}，整片颜色均匀、无渐变、无纹理，不要出现台面、桌面或地面。{投影规则}。背景不与产品发生色彩混合：产品与白盘表面不出现该背景色的反光、溢色或染色，白盘保持中性白，产品原本的红棕色调不被背景色带偏，边缘不泛该背景色
```

`{投影规则}` 按底色明暗取：深色底用「盘底一层柔和自然的接触阴影，紧贴盘底、不外扩」；中浅色底用「盘底一层极淡柔和的自然投影勾出盘缘」。

**C. 场景背景**

需要用户指定 `{{scene}}` 与 `{{scene_light}}`，未指定时不要自行编一个。

```
背景为{{scene}}，场景整体处于浅景深虚化状态，只有白盘与产品保持清晰，场景不抢焦点；场景中不出现任何文字、品牌、logo、第二份食物、餐具以外的杂物或人物。场景带有{{scene_light}}，环境光参与画面氛围，可以给白盘边缘、产品轮廓和场景深处带一层有方向的微光过渡，让画面有空气感和热食的温度感；但环境光不得改变产品本身的红棕本色，不把白盘整体染成环境光的颜色，产品表面不出现大面积的背景色反光块。白盘放在场景中，盘底有与场景材质相符的柔和接触阴影，投影方向与主光一致，主光来自左前45度、阴影落向右后方
```

**场景背景与纯色背景的区别**：纯色背景要求完全不染色（那是为了抠图和色准）；场景背景**允许、而且需要环境光**，否则画面会像贴图。界限是：环境光可以做氛围、可以做边缘微光，但不能改变产品本色、不能把白盘整体染色。

**C 的子类一：场景类型（6 个，附自由输入）**

| 场景 | 效果 |
| --- | --- |
| 深色老木桌面 | 最通用的卤味场景，木纹虚化后暖调衬红棕，最稳 |
| 竹编垫／竹席 | 中式感强，纹理细密，虚化后不抢焦点 |
| 深灰石板／水泥台面 | 冷调硬质，与暖色卤味形成冷暖对比，偏高级 |
| 粗麻布／亚麻布 | 柔软粗糙、家常感，但容易显廉价，需压低饱和 |
| 暗调木托盘 | 器物感强，适合单品特写 |
| 中式青砖／老墙 | 复古感，纹理容易乱，必须重虚化 |

**C 的子类二：`{{scene_light}}` 环境光（5 个）**

| 取值 | 文本 | 效果 |
| --- | --- | --- |
| 暖调环境光（默认） | `暖黄色的环境光，像店内暖灯或烛光` | 热食感最强，红棕更浓 |
| 自然光 | `窗边自然日光，冷白偏柔` | 干净通透，适合清爽款 |
| 冷暖对比 | `主光偏暖、环境偏冷的环境光` | 层次最丰富，高级感 |
| 弱环境光 | `很暗的环境光，只有主体受光` | 氛围沉，突出轮廓光 |
| 无环境光 | `不额外添加环境光，只有主光照明` | 最接近纯色底的干净感 |


**选背景时的取舍提示**（可主动告诉用户，但不要替他决定）：

| 子类 | 适合 | 代价 |
| --- | --- | --- |
| T 透明底 | 需要换多种底色、做主图素材库 | 部分模型做不出真透明，会返回实底或把棋盘格画进画面 |
| S1 纯白底 | 通用电商主图，平台适配最稳 | 白盘与白底对比弱，要靠投影勾盘缘 |
| S2 黑底 | 高端感、突出红棕油亮与轮廓光 | 白盘在黑底上反差大，容易显生硬；阴影控制不好会发灰 |
| S3 绿幕色 | 后期要批量抠像换景 | 容易出绿色溢色，需在提示词里明确禁止；不适合直接当成品图 |
| S4 蓝幕色 | 同上，产品偏绿或偏黄时比绿幕更好抠 | 同上，且蓝色溢色在深色卤味上更明显 |
| S5 自定义纯色 | 有固定品牌色或页面底色 | 色值要准确给出，深浅不同会影响投影规则 |
| C 场景背景 | 详情页、内容图、有氛围需求 | 变量最多、最不可控：容易出杂物、文字、第二份食物，场景光位也容易和主光打架 |

## 4. 生成设置

| 项目 | 值 |
| --- | --- |
| 渠道 | magpie-image（`mcp__magpie-image__generate_image`），当前会话未连接时说明并让用户改选可用渠道 |
| 模型 | **不锁定**。使用所选渠道当前默认模型，实际模型以工具返回信息为准 |
| 尺寸 | 优先 `1024x1024`（或按 `{{ratio}}` 换算的等价尺寸）；按工具实际支持情况设置 |
| 质量 | 工具支持质量设置时用 `high`；不支持时不传此参数 |
| 数量 | `n = 1`，每次调用只出一张 |
| 参考图 | 同时传入参考图1：1 张该品项实拍图；参考图2：固定空盘素材。参数名、顺序和传图方式按所选工具的实际能力核实 |
| 背景参数 | 仅选 T 透明底时启用所选工具实际支持的透明背景参数并存 PNG；例如 Magpie 用 `background: "transparent"`，原生生图用 `transparent_background: true`。选 S 纯色或 C 场景时不启用透明背景，靠提示词描述背景 |
| 输出格式 | `.png`；透明底必须 PNG。实底图存 PNG 或 JPG 均可，按工具真实返回格式记录 |

**模型策略**：不指定模型，使用所选渠道的当前默认设置。每次调用前不要假设用的是哪个模型；仅当工具返回模型信息时记录实际模型。

**透明底核验（必做）**：拿到图后先确认是否真带透明通道，再交付：

```python
from PIL import Image
im = Image.open(path)
has_alpha = im.mode in ("RGBA", "LA") and im.getextrema()[-1][0] < 255
```

`has_alpha` 为 `False` 说明是实底图，按 §7.5「透明底不可用时的处理」让用户重选背景，不要直接当透明底交付。

**已知伪透明坑**：部分模型（实测 `rightcode-image/gpt-image-2.5`）收到 `background:"transparent"` 时不返回 alpha 通道，而是把灰白**棋盘格直接画进画面**，文件仍是 RGB。只看四角像素会误判成「纯白底」，必须用 `Image.open().mode` 判断，并多点采样确认是否出现双色棋盘格。遇到这种图有两个选择：交给用户自行处理，或走抠图脚本方案（按中性度分离 + 只取与画面四边连通的连通域 + 向内收 2px 去混色带 + 边缘取最近内侧实色替换，最后 alpha 羽化）。

**失败处理**：返回 `drew nothing`、空结果或超时，视为**结果待核实**，可能已消耗额度。不自动重试、不切换模型试探、不靠试生成检测可用性。如实告知用户，取得新的单张确认后再决定是否重试。

## 6. 硬性禁则

1. **模板正文不得出现任何具体品项的专属词**（肌肉块、筋膜、膜翼、肠壁、橄榄形等）。形态一律走 `{{product_structure}}` 与 `{{product_guard}}`。这条是「生成的东西和参考图不是一回事」的首要原因。
2. 参考图仅限当前品项实拍图和本技能的固定空盘图，分别用于锁定产品和盘子；不传其他风格图或竞品图。
3. 不写「轮廓紧凑完整」「筋膜不外扩」「不形成翼状轮廓」等收边描述。
4. 尺寸不用百分比或倍数关系，改用「四周留白宽度大于一件本身」这类可视觉判断的描述；细长盘绕类必须用对应的 `{{size_anchor}}` 预设。
5. 多件模板必须保留差异清单，避免复制粘贴感。
6. 多件模板必须保留 `{{unit_integrity}}`，避免散成多块。
7. 不锁定模型：不传 `model` 参数；失败时不自动重试、不切换模型试探。
8. 画面默认无文字；用户要文案就后期加，不让模型渲染。
9. 每次只生成 1 张，不用 `n>1` 或组图一次出多张。
10. 盘面默认不出现辣椒、白芝麻等任何点缀。用户临时要求加点缀时只在当次生效，不改动本文件的默认值。
11. **背景必须由用户选择，且分两级问**：第一轮只给三个大类（透明／纯色／场景），第二轮再展开子类。不要一次把六个子类摊给用户，也不要替他决定。例外：用户最初的请求里已描述场景，跳过第一轮直接默认场景背景。用户未指定时用 T 透明底并明确告知用的是默认值。
12. 不因为「白底更稳」「透明底做不出来」就自行换背景；换背景属于改变方案，必须先告知并取得同意。
13. **纯色背景（S1–S5）不得删掉「背景不与产品发生色彩混合」那段**。缺了这段，底色会反光到白盘和产品上，颜色发偏。
14. **场景背景（C）不得自行编造场景**。必须由用户确认，或从用户最初请求里明确提到的场景提取；提取的要写进确认卡让用户核对。
15. 场景背景必须写清「浅景深虚化、不抢焦点、不出现文字品牌 logo 第二份食物杂物人物」、「投影方向与主光一致」，以及环境光（`{{scene_light}}`）。
16. **场景背景允许环境光，纯色背景不允许**。两者不要混写：纯色背景写「背景不与产品发生色彩混合」；场景背景写「带环境光、可做边缘微光，但不改变产品本色、不把白盘整体染色」。场景背景里若写了「完全不染色」会把氛围做死。
17. 透明底不写「纯白色」「#FFFFFF」「色温」「投影」等白底专用描述；黑底、绿幕、自定义色同理，只写该背景自己的描述，不要混写。
18. 透明底必须存 PNG，不存 JPG。绿幕／蓝幕也建议 PNG，避免 JPEG 压缩把纯色压出噪点影响抠像。
19. **不写会削弱产品光泽的表述**：产品表面的「哑光」「避免反光」「不要高光」「降低油光」一律不写（餐具的「哑光陶瓷」不受此限）。要控制塑料感，用「高光要碎、沿纹理断续、有形状变化」正向描述。
20. 光泽不足时先检查是不是漏了「顶部窄束小硬光打点状高光」——只靠大面积柔光出不来油亮。

## 7. 批量执行流程

### 7.1 整理输入

接收单项、列表或表格，每行默认对应一张，按用户标识或输入顺序编号。先确认总项数，再开始。检查必填变量（`product_name`、`product_structure`、`reference_image`），只追问缺失内容，可选项用默认值。

**背景分两轮问**，不要沿用上一批的隐式默认，也不要一次把全部子类摊给用户。

**第一轮只问大类，三选一**（可以和「项数」合并进同一轮）：

| 大类 | 一句话说明 |
| --- | --- |
| 透明 | 没有背景，只有白盘和产品，可自由换底 |
| 纯色 | 单一底色，最稳、最通用 |
| 场景 | 有环境、有环境光，最像实拍，但最不可控 |

用户答「你定」时才用 T 透明底，并明确告知用的是默认值。

**第二轮按大类展开**：

- 选 **T 透明** → 不再问，直接进入确认。
- 选 **S 纯色** → 给 5 个颜色子类：S1 纯白／S2 黑／S3 绿幕／S4 蓝幕／S5 自定义色（选 S5 要色值），并说明各自代价（见 §2.4 取舍表）。
- 选 **C 场景** → 同一轮问两件事，不要拆成两轮：场景类型（6 个，见 §2.4）+ 环境光（5 个，见 §2.4）。

**例外：用户最初的请求里已经描述了场景**（例如「放在木桌上」「要有竹垫」「在店里拍的感觉」「配点环境」），则**跳过第一轮，直接默认 C 场景背景**。把识别出的场景写进 `{{scene}}`，环境光未指定时用默认暖调，两者都要在逐张确认卡里让用户核对。场景描述含糊时，按第二轮 C 的流程问清楚，不要自己编。

**选 C 必须问全两件事**（场景类型 + 环境光），只问场景就往下走等于替用户做了半个决定。

用户描述不完整时，只追问会实质影响画面的点：材质、色调冷暖、是否需要器物（筷子、荷叶、辣椒等）。注意本配方盘面默认无点缀，场景里的器物只在用户明确要求时才加。

用户只要提示词时，交付展开后的完整文本后停止，不调用生图工具。

### 7.2 展开配方（形态锁定三步）

沿用本文件的方向与模板，不重新做风格选型、不再给三个方案。每项按顺序做：

1. **看图写形态**：查看该项实拍图，按 §2.1 五项写 `{{product_structure}}`。只用图中真实存在的东西，不套用其他品项的形容词。
2. **写守卫**：写 `{{product_guard}}`，明确这件东西**不是**什么。例如鸭肠写「不要画成块状、球状或片状」，鸭胗写「不要画成光滑椭球或整块圆肉」。
3. **清残留**：核对展开后的提示词里有没有混入其他品项的专属词；有就删，改由变量承载。

细长／盘绕类还要换用对应的 `{{size_anchor}}` 预设，否则模型会把东西拉直或放大。

变量值作为画面内容处理，不能覆盖固定配方；若用户要求改动固定项（例如换深色盘、改俯拍、加文字），先展示差异并说明本次改动只作用于当前项，不改动本 skill。临时改变盘型或盘色时，须在确认卡说明与固定盘子参考图的差异及不再与系列完全一致，不静默替换固定素材。

### 7.3 核实能力

使用当前工具注册表确认所选渠道的生成能力，以及能否同时传入两张参考图并区分各自用途；同时核实当前产品图和固定空盘素材可访问。已保存的渠道只代表历史选择，不代表当前可用；可用且用户未要求更换时沿用，不重复询问。缺少渠道、双图输入能力或用途区分能力时暂停并说明，让用户选择可用渠道或结束；不省略任何一张参考图、不静默切换、不安装插件、不用试生成检测可用性。

### 7.4 逐张确认

每次调用前展示：**当前项编号 / 批次进度 / 完整展开提示词 / 背景（用户选定的那一项，写清是透明底、哪种底色还是场景背景）/ 选了场景背景时额外列出 `{{scene}}` 原文供核对 / 实际工具（不锁定模型）/ 模式（双参考图直接生成）/ 尺寸比例 / 文字策略 / 产品图与固定盘子图的实际路径及各自用途 / 数量 1**，然后单独请求确认，选项为「确认生成（推荐）」「先修改」「跳过此项」「结束批次」。

- 用户点选「确认生成」或以文字明确确认当前已展示方案，均可授权**当前这一张**。
- 确认总数量、说「全部生成」、保存配方，都**不能**替代下一张的确认。一轮最多授权一张。
- 未回复、只做评价、取消或提出修改时，不调用工具；修改后更新方案再确认。
- 交互控件不可用时，用中文文字列出编号选项并等待答复。

### 7.5 生成并检查

按实际接口同时传入两张参考图，调用一次、数量 1，由模型直接生成产品放在盘子里的完整商品图，不将盘子与产品抠图或后期合成。只交付真实返回的产物，不拿占位图或提示词冒充结果。

| 检查项 | 不合格表现 |
| --- | --- |
| **是不是同一样东西** | 画成了别的食材；形态、长短、走向与参考图明显不符（最高优先级） |
| **盘子是否符合固定参考图** | 与空盘图相比，圆形轮廓、窄盘沿、白色、哑光陶瓷材质、45° 视角或盘子在画面中的位置和比例明显变化；不合格时标记并说明，不当作统一系列成品 |
| 件数对不对 | 多件版视觉上翻倍（散成 2N 件） |
| 件间差异是否自然 | 几件一模一样，复制粘贴感 |
| 光泽是否够 | 表面发干发哑、没有点状高光、油膜不透亮、整体像干壳 |
| 光泽是否过假 | 一整片平滑连续的镜面反光，没有形状和明暗变化 |
| 是否真透明 | 返回实底图（白底、灰底、棋盘格被画进画面） |
| 盘缘是否干净 | 透明底出现白色/灰色描边、光晕、毛边 |
| 背景是否按用户所选 | 擅自换成透明底或白底；绿幕被做成渐变；黑底发灰 |
| **背景有没有染到产品颜色** | 白盘泛底色（泛绿、泛蓝、泛灰、泛黄）；产品红棕调被带偏；产品或盘沿出现背景色的边缘光 |
| 场景是否抢焦点（仅 F） | 场景清晰度过高、纹理盖过主体；出现文字、品牌、logo、第二份食物、杂物、人物 |
| 场景光位是否一致（仅 F） | 阴影方向与主光（左前45度、阴影向右后）不符，产品像是贴上去的 |
| 环境光是否过头（仅 F） | 产品红棕被染成橙红或紫红、白盘整体变色、大面积反光块盖住纹理；或反过来完全没有环境光、画面像贴图 |
| 主体是否压盘沿 | 出盘、压边 |
| 尺寸占比 | 明显撑满盘子 |
| 文字 | 出现任何文字、水印、外文 |

「是不是同一样东西」不过关时，按这个顺序排查，不要直接重生成：

1. 传入的参考图是不是该品项本身
2. 提示词里有没有混入其他品项的专属词
3. `{{product_structure}}` 是否只是泛化形容词、没有写清形态骨架
4. 细长／盘绕类是否误用了「长度」类尺寸锚点

偏差如实说明，不自动修图、不自动重试。需要重出时展示修正后的提示词并重新取得确认。

**透明底不可用时的处理**（仅在用户选了 T 透明底、且所选渠道的透明背景设置实际无效时走）：

1. 告知用户：当前渠道/模型返回的是实底图，透明通道不可得；工具有返回实际模型名时一并说明。
2. 让用户重新选背景，按 §7.1 的两级流程重走一遍（第一轮透明／纯色／场景，第二轮子类），另加「保留实底图由用户自行抠图」「结束该项」两个出口。**不要默认换成纯白底就交付。** 选场景时仍要问全场景类型与环境光。
3. 用户选定后，把 `{{background}}` 换成对应预设重新出图，并在交付时标注实际用的背景。

### 7.6 记录与恢复

在当前对话用紧凑清单记录：项编号、变量值、状态（待确认／完成／失败／结果待核实）、真实产物路径。失败后暂停；超时或结果不明标记为「结果待核实」，不得当作未执行而自动重试。恢复批次时先核对记录、跳过完成项，对不明结果只做只读核查；仍无法确定时告知可能消耗额度，取得新的单张确认后才重试。

## 9. 光泽调节（用户说「不够油亮」或「太假了」时）

光泽同时受两股相反的力拉扯：柔光与哑光描述会把油光压没，镜面反光又会变成塑料感。按下面这张表调，一次只动一项。

| 现象 | 改哪一句 |
| --- | --- |
| 发干、没有油亮 | 补「顶部偏前窄束小硬光打出 2–4 个锐利点状高光」；把「油膜薄」改成「油膜饱满」；加「低洼处卤汁积成较厚油层」 |
| 亮但平、像塑料 | 加「高光沿表面纹理的凹凸断断续续分布，大小不一、形状不规则」；删掉任何「连续高光带」表述 |
| 整体偏暗、看不出食欲 | 加强背逆光描述：「背逆光穿过油膜呈半透明琥珀红」；颜色改「浓郁饱和、油亮处偏暖偏亮」 |
| 凹陷处死黑 | 补「左前低角度白色反光板补光，凹陷与缝隙处带一层湿润反光」 |
| 表面过于光滑、像卤蛋 | 回到 `{{product_structure}}`，检查是否漏写表面纹理、边缘撕裂感、断口形态；形态细节不足时，模型会用光滑高光去填 |

不要用「降低油光」「避免反光」这类否定式去压塑料感，实测会连真实光泽一起压掉。

## 10. 已知限制

- **透明底是否可得取决于所选渠道和实际模型**。透明背景参数只对支持的模型生效，模型不锁定时无法预先保证；每张都要核验 alpha 通道，不通过就按 §7.5 让用户重选背景。
- **纯色背景仍可能染到产品**。写了「背景不与产品发生色彩混合」能大幅降低概率，但绿幕、高饱和色、大面积深色底仍可能让白盘泛色或产品边缘带边缘光。出图后要专门看白盘是不是还是中性白；发偏就说明底色溢上来了，需重出或后期校色。
- **纯色背景容易被模型做成渐变或有明暗起伏**。绿幕／蓝幕必须整片均匀才能抠像，出图后要检查四角与中心色值是否一致；不一致时不要当绿幕交付。
- **场景背景最不可控**。容易出杂物、文字、第二份食物，或场景清晰度过高抢焦点；也常出现场景光位与主光打架、产品像贴上去。逐张必查，不要整批跑完再挑。
- **场景环境光的强度不好卡**。写「可以有环境光」后，模型容易走两个极端：要么环境光过强，把红棕染成橙红、白盘整体变色；要么几乎不出环境光，画面又变回贴图感。出图后按检查表「环境光是否过头」判断；偏强就在 `{{scene_light}}` 里加「环境光只做边缘微光、不进产品表面」，偏弱就换成「暖调环境光」或「冷暖对比」。
- **绿幕／蓝幕会有溢色**。模型可能把绿色反光打到白盘和产品边缘，抠像后边缘发绿。提示词已写禁止，但实测不能保证完全干净；要求高时建议改用透明底或纯色底自行抠图。
- **黑底与白盘反差大**。黑底能突出红棕油亮，但白盘会显得突兀生硬；用户觉得生硬时，可建议换深灰或米白盘，但要先征得同意。
- **模型不锁定**，实际模型由所选渠道的当前设置决定。若批次中途默认模型变化，风格、光泽强度和形态还原度可能漂移；察觉同批前后两张观感不一致时，如工具返回了模型信息则说明差异，由用户决定继续还是统一重出。
- **形态还原度不是 100% 可控**。参考图能大幅提高一致性，但模型仍可能改变长短比例、盘绕方式或表面细节。要求严苛时建议一次只出一张、逐张检查，而不是整批跑完再挑。
- **盘子参考不能保证像素级一致**。双参考图可以约束同款盘子的形状、盘沿、材质和视角，但模型仍可能产生细微差异；多图也可能干扰食品形态，须逐张同时核对产品图与盘子图。
- 白盘放在透明底上时，盘缘与透明区缺乏背景对比，容易出现白边或糊边；若反复出现白边，改用略偏米白或带极浅灰调的盘可缓解，但要先征得用户同意。
- 模型对「占盘径 X%」这类数值基本不执行，实测仍会偏大。要严格统一占比，建议后期裁切，比反复重生成更可控。
- 单件图通常比多件图里的单件略大，这是主图放大展示细节的常规做法。
- 45° 俯视下最前方那件因近大远小会略大，属物理正确的透视，不视为大小不齐。
- 本配方只保证视觉方向一致，不保证多张之间像素级一致。
